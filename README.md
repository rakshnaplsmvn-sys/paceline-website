# PACELINE — Frontend Recruitment Task

A responsive two-page running gear storefront recreated from the supplied DCS Frontend design files using HTML, CSS and JavaScript.

## Pages
- `index.html` — homepage, categories, product cards, story, running collections and newsletter.
- `about.html` — brand story, values, timeline, store map and founder profiles.

## Run locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
4. Keep the `assets` folder alongside the HTML files. Do not move individual images out of it.

No package installation or build step is required.

## Interactions
- Responsive mobile navigation.
- Product category filters.
- Wishlist toggle buttons.
- Add-to-bag demo counter.
- Newsletter form validation and feedback.
- Search prompt demo.

## Notes
This is a frontend demo. The shopping bag, search, and newsletter are not connected to a backend, payment service, or mailing list. Product cards use the supplied product image as a visual placeholder because the provided design pack contains one arrival product image.

## Deployment
You can deploy this static site on Netlify, Vercel, or GitHub Pages. Upload the entire project folder, including `assets`, `index.html`, `about.html`, `style.css`, and `script.js`.
